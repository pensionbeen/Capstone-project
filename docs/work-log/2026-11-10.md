# 2026-11-10 · X-002 Windows 게스트 설치 시작

- Oracle 서명이 유효한 설치 파일과 `VBoxManage 7.2.20r175154`를 확인했다. MSI는 종료 코드 0을 반환했다. 본체만 설치했고 USB, 선택형 네트워크 드라이버, Python은 제외했다. Smart App Control, Defender 실시간 보호, VBS와 컴퓨터의 Root·TrustedPublisher 인증서 목록을 설치 전과 대조해 같은 값을 확인했다.
- 재부팅 전에 받았던 한국어 x64 Windows ISO의 SHA-256은 Microsoft의 공개값과 일치했다. 새 `ORBIT-X002` VM의 SATA에는 D:에 만든 최대 80GiB 동적 VDI 1개와 읽기 전용 DVD 2개(Windows 설치본, X-002 시험 매체)를 연결했다. VM 폴더는 `D:\VirtualBox VMs\ORBIT-X002`다.
- CPU 2개, 가상 TPM 2.0, EFI Secure Boot, NAT를 설정했다. 호스트 가용 RAM이 약 6.2GiB여서 VM에는 4GiB를 배정했다. 공유 폴더·클립보드·드래그 앤 드롭·USB는 꺼져 있다.
- Windows 선택 기능 WHP는 비활성으로 조회됐지만 VirtualBox가 기존 Windows 하이퍼바이저에서 파티션을 생성하고 실제 한국어 설치 화면을 표시했다. 추가 기능 활성화나 호스트 재부팅은 수행하지 않았다. 첫 DVD 입력 시간을 놓친 뒤 빈 VM만 재시작하여 가상 DVD로 부팅했다.
- 언어·키보드를 확인하고 새 VDI의 경로·UUID·형식·용량을 대조한 후 설치 옵션을 진행했다. 인계 시점은 게스트의 제품 키 화면이다. 사용자가 VM 안에서 라이선스에 맞는 에디션과 로그인 절차를 진행한다. 게스트 바탕 화면이 준비되면 기존 정책 상태에서 시험 매체의 `run.ps1`로 가짜 파일 읽기부터 확인한다. 게스트의 X-002와 T-014는 미검증이다.
