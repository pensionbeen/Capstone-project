## 결정·자동화 범위

- **A-07 자동 보조 호출 기준안:** 주담당이 작업·위험·병렬 검토의 이점을 분류하고 요청 모델을 지정한다. [실행기 사용법](../../experiments/x-001-ai-terminal/README.md), [규칙 원문](../AI_WORKFLOW.md). 기록만으로 세션 모델 전환을 주장하지 않는다.
- --probe는 경계값 오류가 있는 가짜 코드만 보낸다. --packet은 필요한 자료를 명시적으로 전달하는 제한된 검토 어댑터다. 쓰기 작업을 무인 위임하는 실행기는 이번에 구현하지 않았다.
- Codex 모델 목록에 지정 모델이 없으면 중단한다. 기본 High, Astra는 Max 우선, Ultra는 독립 병렬 검토가 유용하고 목록에 있을 때 선택한다. 목록과 실제 호출 성공은 따로 기록한다.
- 기존 Gemini CLI의 3.1 Pro Preview와 사용자가 실제 로그인한 Antigravity의 Gemini 3.1 Pro (High)를 구분한다. Antigravity는 기존 Google 로그인을 유지하며 설치 버전의 실행별 읽기 전용 방법을 조사한다. 기본 headless/Plan/종료 0은 쓰기 금지 증거가 아니다.
- Codex는 JSON 대신 텍스트 모드의 첫 설정 헤더와 stdout 최종 응답을 회수한다. CLI_RESOLVED_CONFIG는 CLI가 확정한 모델/추론 설정이며 원격 모델 신원 인증이 아니다. 출력에서 도구 활동이 없다고 모든 도구/훅 미사용을 입증하지 않는다. 모델 변경 알림·권한 불일치는 사용 보류다.
- Codex 0.160.0은 login status와 exec의 CODEX_API_KEY 처리 방식이 달라, 키/엔드포인트 override 환경변수가 있으면 값 출력 없이 호출 전에 중단한다. 전후 파일 검사 자체가 실패한 경우도 전체 중단·잠금 유지한다.
- 같은 폴더는 Codex 한 명만 수정한다. 이번 보조 에이전트는 코드·공식 소스 검토만 했다. 실행기 잠금은 외부 AI 전체를 통제하지 않는다.
- 일반 PowerShell 실행은 사용자가 한 번 시작해야 한다. 이 세션은 설치 폴더/네트워크 권한을 자동 획득할 수 없고 외부 실행 승인 범주도 비활성이다. 재설치·보안 완화·우회 실행 장치는 만들지 않는다.

## 검토 반영과 한계

필수 옵션 누락을 READY로 처리한 문제, CLI 오류 종료를 성공 코드로 반환한 문제, 시간 초과 뒤 파이프 잔존, Gemini 환경변수 우회, 제한적인 무변경 검사, 관리자 설정 경로 불일치를 채택·수정했다. 후손 전체 정리는 해결했다고 주장하지 않고 시간 초과 시 후속 호출 중단·잠금 유지로 제한했다.

Gemini v0.62.0 소스에서 Plan→YOLO 전환, 정책 우선순위/오류 뒤 계속 실행, 빈 MCP 목록의 의미, 설정 로더의 자동 저장, admin 필드 처리, 모델 대체/init 표시 한계를 확인했다. 설정 로더를 ‘읽기 전용 검사’로 호출하는 안은 채택하지 않았다. 개인/관리자 설정을 덮거나 권한 제한을 해제하지 않는다.

24개 검사는 실행 도구 자체의 증거다. Codex 서비스 응답은 별도 사용자 실행 결과로 확인했다. 수정된 모델 헤더·Antigravity 옵션/읽기 전용 제한·Pro 응답·한도·PTY는 실측이 남는다. @ 제한, 제한된 개인 설정 지원, 타임아웃/파일 검사 실패 후 후손 확인도 남는다.

정정: .gemini/settings.json의 Gemini CLI 인증 선호값을 Antigravity의 실제 인증이라고 해석한 설명을 철회했다. 사용자가 제공한 Antigravity Google AI Pro 배너를 해당 프로그램의 로그인 표시 근거로 사용한다. Gemini CLI의 ide.hasSeenNudge는 공식 스키마상 UI 안내 확인 여부이므로 boolean만 허용했다. 인증 파일/토큰/이메일은 문서에 저장하지 않았다.

## 다음 실행·중단 기준

1. Codex 메타데이터 조사는 수령했다. 같은 사용자 환경에서 `ai-review.mjs --probe --provider codex`로 수정된 헤더 관측을 검증한다.
2. `agy-capabilities.mjs`는 Antigravity 버전/help만 조사한다. 읽기 전용 실행 경계가 확인된 뒤 실제 Gemini 검토를 호출한다. 기존 Google 로그인과 전역 설정을 보존하며 기본 모드로 성급히 실행하지 않는다.
3. 응답 확인 뒤 node-pty 설치·lockfile 검토 → 준비 검사 → 가짜 PTY → 실제 Codex TTY 순서다.
4. X-001은 기존 4~8h 예상·8h 판단 한도를 유지한다. 자동화 추가 공수가 필요하면 일정에 숨겨 넣지 않고 재계획한다.
5. 조건이 계속 막히면 T-002 첫 창·폴더 선택은 독립 진행 가능하다. T-003 통합은 두 선행 결과 후이며 X-001을 미리 완료 처리하지 않는다.
