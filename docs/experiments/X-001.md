## 결정·자동화 범위

- **A-07 자동 보조 호출 기준안:** 주담당이 작업·위험·병렬 검토의 이점을 분류하고 요청 모델을 지정한다. [실행기 사용법](../../experiments/x-001-ai-terminal/README.md), [규칙 원문](../AI_WORKFLOW.md). 기록만으로 세션 모델 전환을 주장하지 않는다.
- --probe는 경계값 오류가 있는 가짜 코드만 보낸다. --packet은 필요한 자료를 명시적으로 전달하는 제한된 검토 어댑터다. 쓰기 작업을 무인 위임하는 실행기는 이번에 구현하지 않았다.
- Codex 모델 목록에 지정 모델이 없으면 중단한다. 기본 High, Astra는 Max 우선, Ultra는 독립 병렬 검토가 유용하고 목록에 있을 때 선택한다. 목록과 실제 호출 성공은 따로 기록한다.
- Gemini 3.1 Pro Preview는 **명시 후보**이며 계정 이용 가능성 미확인이다. 도구 없는 텍스트 검토·최소 설정 검사·확장/스킬/후크 제한·MCP 제외를 준비했다. Plan 모드를 읽기 전용의 근거로 쓰지 않는다.
- CLI 헤더/사용 통계가 없으면 실제 모델 미확인이다. 속도·AI 자기 소개·성공 종료로 대신 확인하지 않는다. 내부 다른 모델 사용이 관측되면 거부·보고한다. 모든 내부 대체 시도를 사전 차단했다는 보장은 아직 없다.
- 같은 폴더는 Codex 한 명만 수정한다. 이번 보조 에이전트는 코드·공식 소스 검토만 했다. 실행기 잠금은 외부 AI 전체를 통제하지 않는다.
- 일반 PowerShell 실행은 사용자가 한 번 시작해야 한다. 이 세션은 설치 폴더/네트워크 권한을 자동 획득할 수 없고 외부 실행 승인 범주도 비활성이다. 재설치·보안 완화·우회 실행 장치는 만들지 않는다.

## 검토 반영과 한계

필수 옵션 누락을 READY로 처리한 문제, CLI 오류 종료를 성공 코드로 반환한 문제, 시간 초과 뒤 파이프 잔존, Gemini 환경변수 우회, 제한적인 무변경 검사, 관리자 설정 경로 불일치를 채택·수정했다. 후손 전체 정리는 해결했다고 주장하지 않고 시간 초과 시 후속 호출 중단·잠금 유지로 제한했다.

Gemini v0.62.0 소스에서 Plan→YOLO 전환, 정책 우선순위/오류 뒤 계속 실행, 빈 MCP 목록의 의미, 설정 로더의 자동 저장, admin 필드 처리, 모델 대체/init 표시 한계를 확인했다. 설정 로더를 ‘읽기 전용 검사’로 호출하는 안은 채택하지 않았다. 개인/관리자 설정을 덮거나 권한 제한을 해제하지 않는다.

21개 검사는 가짜 입력과 호출 도구 자체의 증거다. CLI 옵션·표시 형식·읽기 전용 제한 적용·Pro 서비스·한도·PTY는 실측이 필요하다. 모델 사용 불가/한도 초과는 자동 구매나 하위 모델 전환 사유가 아니다. @ 제한, 최소 개인 설정만 지원하는 보수적인 차단, 타임아웃 후 후손 확인 필요도 남는다.
