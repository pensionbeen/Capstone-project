# 요구분석과 기능 초안 사용 안내

실제 프로젝트 폴더를 고른 뒤 Codex를 선택하고 **AI로 요구분석 시작**을 누릅니다. 현재 지원 조합은 Windows x64·Codex CLI 0.162.1·기존 ChatGPT 로그인입니다. 다른 버전이나 로그인 실패는 안내 후 실행을 막습니다.

1. **연결 준비 확인** 후 만들고 싶은 서비스를 입력하고 **목표 보내고 질문받기**를 누릅니다. 목표는 최대2,000자입니다.
2. AI 질문을 읽고 답변·정정 내용을 보냅니다. 답변은 최대6,000자이며 같은 대화로 이어집니다. 목표 수정 실행이 실패하면 목표를 다시 보낸 뒤 답변합니다. Enter는 줄바꿈, Ctrl/⌘+Enter는 전송이며 한글 조합 중에는 전송하지 않습니다.
3. **대화로 기능 초안 만들기**를 누릅니다. AI 응답을 검사한 뒤 미리보기를 표시하며 이때 기존 기능이나 검증 결과는 바뀌지 않습니다.
4. 이름·설명·완료 조건·묶음·선행 관계·관련 경로를 확인하고 수정합니다. 기능을 직접 추가하거나 삭제할 수 있습니다. 제외 항목은 적용 시 저장되지만 진행률 계산에서 빠집니다.
5. **초안 적용**을 누르면 기존 기능·검증 기록을 보존하고 새 기능을 추가합니다. 같은 제목·전체100개 초과·잘못된 관계 등은 적용을 거부합니다. 저장 실패 시 편집한 초안을 유지하므로 내용을 확인하고 다시 적용할 수 있습니다.

**초안 취소**는 현재 초안만 버립니다. 초안 생성 후 새 답변이나 목표 변경으로 대화가 바뀌면 이전 초안의 적용을 막으며 취소 후 다시 생성할 수 있습니다. 생성 실패·중단·잘못된 JSON 응답은 기존 목록을 바꾸지 않습니다. 자동 재전송은 하지 않습니다.

화면을 이동해도 현재 실행은 이어지고 입력 초안은 유지됩니다. 실행 중에는 다음 답변을 적을 수 있지만 전송과 기능 적용은 정리가 끝난 뒤 가능합니다. **실행 중단**은 로컬 실행의 정리 결과까지 표시합니다. 정리가 확인되지 않으면 새 실행을 막습니다.

ORBIT의 대화 표시·목표/답변 입력·미적용 기능 초안은 앱 창을 닫으면 복원되지 않습니다. 적용한 기능은 SQLite v3에 저장되어 재시작 후 복원됩니다. 대화 영구 저장은 T-012 후속입니다. 요구분석과 일반 대화는 구분하며 열린 요구분석에 일반 메시지를 섞어 보내지 않습니다.

목표·답변은 로그인한 Codex 서비스에 전송됩니다. 앱은 계정의 남은 사용량·비용을 조회하지 못합니다. AI 초안과 완료 주장은 실제 검증 근거가 아니며 완료 처리는 [수동 검증](VERIFICATION.md)을 따릅니다. 파일 접근 보호·앱 Gemini 실행은 후속입니다.

## 개발·검증 경계

- 생성 응답은 CLI의 마지막 응답 파일에서만 읽고 최대128KiB·UTF-8·엄격한 필드·중복·순환·깊이16·경로를 검사합니다. 앱이 새 UUID와 초기 상태를 부여하며 AI의 검증/완료/버전 필드를 거부합니다.
- 임시 파일은 매 실행마다 새 전용 폴더에서 생성하고 해당 파일·폴더만 정리합니다. renderer가 응답 경로나 대화 ID를 정하지 않습니다.
- 인증된 로컬 API와 IPC 발신자·프로젝트·실행 ID 대조를 거칩니다. 기존 저장 규칙·SQLite 버전·검증 이력 보존을 유지합니다.
- 실행 증거·화면·DB·로그는 `.runtime/` 또는 전용 임시 폴더에 두고 커밋하지 않습니다. 검사 결과와 실패 이력은 [최신 작업 기록](work-log/2026-10-12.md), 분담은 [병렬 개발](PARALLEL_DEVELOPMENT.md)을 따릅니다.
